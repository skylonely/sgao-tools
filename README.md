# SGAO 工具箱

SGAO 的独立开发工具站：[tools.sgao.cc](https://tools.sgao.cc)。输入仅在浏览器内处理，不上传、不保存输入内容，不依赖主站或 API 项目。

源码：[skylonely/sgao-tools](https://github.com/skylonely/sgao-tools)。

## 导航首页与 SEO

根目录 `/` 是工具导航首页，按「图片与图标 / 文档与 PDF / 开发与文本 / 分享与连接」分类，可组合关键词搜索，支持空结果重置与键盘操作。搜索内容只用于本页筛选，不发送请求。

构建时为首页和 13 个工具分别输出完整 HTML：独立的标题、描述、canonical、Open Graph、Twitter Card，以及 WebSite / WebPage / CollectionPage / BreadcrumbList / ItemList 中对应的 JSON-LD。工具页仅包含当前工具的操作界面，并附有实际能力对应的操作步骤、限制、常见问题和相关工具链接。分享预览图为本地的 1200 × 630 PNG，矢量源文件也在 `public/`。

旧 `/#json`、`/#timestamp`、`/#url`、`/#diff`、`/#ico`、`/#image`、`/#qrcode`、`/#svg`、`/#crop`、`/#color`、`/#watermark`、`/#collage`、`/#imagepdf` 地址由浏览器自动替换为独立页面地址，并保留查询参数。普通站内链接为可直接访问的路径；目录入口与说明在未运行 JavaScript 时仍可阅读，工具计算需要 JavaScript。

`/sitemap.xml` 由同一份页面目录生成，包含 14 个规范网址；`robots.txt` 声明站点地图位置。Cloudflare 使用 `force-trailing-slash` 统一 HTML 地址；未知页面返回带 `noindex` 的真实 404。新页面上线后，可在域名所属的 Google Search Console / Bing Webmaster Tools 中提交 `https://tools.sgao.cc/sitemap.xml`；本站不自动操作站长账号。

新增工具时，在 `src/lib/pages.js` 中填写目录、页面文案、步骤、FAQ 与关联工具，在 `src/index.html` 增加对应 `view-*` 区块，并在 `src/app.js` 注册初始化逻辑。构建会同步生成导航、独立页面与站点地图。

## 本地开发

需要 Node.js 22 或更新版本，无需安装依赖：

```bash
npm start
```

打开终端输出的本地地址，默认 `http://127.0.0.1:4173`。修改源码后刷新浏览器即可。

```bash
npm test          # 转换、校验、精度保护和 diff 算法测试
npm run build     # 输出 dist/ 静态资源
npm run preview   # 预览 dist/
```

指定端口：`npm start -- --port 4180`。服务器仅监听本机。

## Cloudflare Workers 部署

项目是纯静态站点；`wrangler.jsonc` 配置了独立 Worker `sgao-tools`、输出目录 `dist/` 和自定义域名 `tools.sgao.cc`。部署账号需要拥有 `sgao.cc` 的 DNS 区域；自定义域名下若已有冲突记录，需要先在 Cloudflare 处理。

手动部署（首次运行会按 npm 提示获取 Wrangler）：

```bash
npx --yes wrangler@4.92.0 login
npm run deploy
```

GitHub 自动部署可沿用主站的 **Cloudflare Workers Builds**：

1. Cloudflare → Workers & Pages → 创建应用 → 导入 Git 仓库，选择独立 `sgao-tools` 仓库。
2. Worker 名称设为 `sgao-tools`，生产分支设为 `main`，根目录保持仓库根目录。
3. 构建命令：`npm ci && npm test && npm run build`。
4. 部署命令：`npx --yes wrangler@4.92.0 deploy`。
5. 首次部署完成后，在 Worker → 设置 → 域和路由中确认 `tools.sgao.cc` 已生效。

首版已通过 Wrangler 手动发布，`tools.sgao.cc` 的 HTTPS 响应已验证。GitHub 推送自动部署需要额外连接 Workers Builds，当前未启用。也可以将 `dist/` 放到其他静态托管服务上。

## 数据处理与边界

- 所有工具在本机计算；静态响应头禁止页面发起数据请求。复制需要浏览器允许剪贴板访问。
- JSON 上限为 2,000,000 个 UTF-16 字符，最多嵌套 200 层；大结果取消语法高亮以降低渲染开销。格式化保留数值文本及重复键，不执行 JSON 中的内容。
- 时间戳自动模式按绝对值 `10¹¹` 区分秒与毫秒；较早的毫秒值请手选单位。秒支持最多 3 位小数，日期输入精确到秒；北京时间固定为 UTC+08:00，本机模式遵守系统时区及夏令时。
- 文本对比统一 CRLF/CR 为 LF；末尾换行参与对比。两侧合计上限 2,000,000 字符、20,000 行。忽略空白会移除全部空白，含行内空格。极大差异按整段展示并提示；结果最多显示 3,000 行，可用「仅看差异」缩小范围。
- 网站图标源图支持 PNG/JPG/WebP/SVG，单张不超过 10 MB、边长不超过 8192、总像素不超过 2400 万。ICO 支持 16/24/32/48/64/128/256 像素，默认合并 16/32/48；以 32 位 BGRA 位图和透明掩码编码为真实 ICO 文件。完整显示等比留白，居中裁剪等比填满。源位图短边小于 512 时提示放大可能模糊。图片与生成内容仅保存在页面内存。
- 不提供后端账户、同步或输入历史；刷新页面会清除输入并显示示例。

## 网站图标整包

入口仍为 `/#ico`，原有书签和单独 ICO 下载继续可用。浏览器本地生成 13 个文件，无新增库或服务：

- `favicon.ico`：使用用户选择的 ICO 尺寸；整包中固定此文件名，单独下载可自定义名称。
- 9 张 PNG：浏览器 16/32/48/96、Apple Touch 180、普通 PWA 192/512，以及 Maskable 192/512。浏览器/普通 PWA 可透明或填自选底色；Apple 与 Maskable 始终填应用底色，Alpha 为不透明。
- `site.webmanifest`、`html-head.txt`、`README.txt`：应用名称/短名称、主题色/底色、打开方式、应用入口、scope/id，以及放置和部署说明。

Apple 图标使用 8% 内边距。Maskable 按源图完整矩形的对角线缩放，保证四角均位于中心半径 40% 的安全圆内，支持宽高比不一的 Logo；完整显示不裁切，用户选择居中裁剪时按其选择裁切。安全区辅助线只用于界面预览，不会写进导出图片。普通与 Maskable 图标分别使用 `purpose: any` 与 `purpose: maskable`。

图标目录和应用入口均为本站绝对目录，可部署到子路径。中文目录自动进行一次 URL 编码，拒绝站外 URL、上级目录、查询/片段和重复编码。HTML 引用使用图标部署目录；Manifest 的图标 `src` 相对自身位置，`start_url`、`scope` 与 `id` 使用独立的应用入口目录。HTML 中用户文本会转义；Manifest 使用 JSON 序列化。

图像设置更新时旧图包立即失效并重新编码，应用文本/路径更新只重新生成配置文件。ZIP 固定平铺 13 个文件，可单独下载每个文件，复制 HTML 和 Manifest。图标预览为效果示意；设备裁切、缓存和安装条件仍需在实际站点检查。此资源包提供图标与配置，站点离线能力需要另外实现。

参考：[Web App Manifest](https://web.dev/learn/pwa/web-app-manifest)、[Maskable 图标](https://web.dev/articles/maskable-icon)、[Apple 主屏幕图标](https://developer.apple.com/library/archive/documentation/AppleApplications/Reference/SafariWebContent/ConfiguringWebApplications/ConfiguringWebApplications.html)。

## 图片智能压缩

入口：[图片压缩 & 格式转换](https://tools.sgao.cc/#image)。输入支持静态 JPG、PNG、WebP、AVIF；输出为 JPG、PNG、WebP，原文件已较优时可保留原格式。每批最多 20 张、单张 20 MB、原图合计 100 MB。解码后最多 3200 万像素、单边最多 10000 像素。动态 PNG/WebP/AVIF 会拒绝处理，避免丢失动画。

- JPG/WebP 通过多轮编码，在 384 像素预览上比较局部亮度 SSIM、颜色误差与透明度，寻找满足预设阈值的更小编码。预设为智能均衡、画质优先、体积优先。这是抽样感知指标，不等于肉眼无损保证，文字、细线及品牌色建议用对比预览检查。
- PNG 使用带 Alpha 的加权中位切分调色板、最近色映射和索引 PNG 编码（PLTE/tRNS/IDAT，zlib 压缩），尝试减少至 256/128/64 等颜色；未通过画质检查时保留原文件或尝试原像素 PNG。没有依赖 TinyPNG 服务或其专有算法。
- 智能模式比较原格式与浏览器支持的 WebP；没有更小的适当结果时保留原文件。显式转换格式或缩小尺寸可能增加体积，界面会如实显示。PNG 减色失败时保留原像素；显式 JPG/WebP 转换无法达到阈值时使用最高编码质量，仍需用户检查画质。
- 浏览器原生编码能力在运行时通过返回 MIME 校验；不支持 WebP 时，智能模式会使用 PNG/JPG 或保留原图，显式转换显示错误，不会把 PNG 改名成 WebP。AVIF 只解码不编码，解码也取决于浏览器支持。
- 不默认缩放原图，可选择最长边上限且不放大；JPG 不支持透明，使用用户选择的底色。重新编码会移除 EXIF 等元数据，保留原文件时不修改元数据。图像显示与颜色管理可能因浏览器不同而有差异。
- 后台按顺序处理，支持停止；无 OffscreenCanvas 时回退到页面画布。文件与结果仅留在当前页面内存。ZIP 使用 STORE 封装（图片已经压缩），支持 UTF-8 文件名、CRC 校验与重名处理；大于 250 MB 时提示分别下载。

## 二维码生成与识别

入口：`/#qrcode`。支持 HTTP(S) 网址、原样文字（含中文和 Emoji）、Wi-Fi 配置（WPA / WEP / 无密码、隐藏网络及特殊字符转义）。内容上限为 1200 个 UTF-8 字节；Wi-Fi SSID 上限为 32 个 UTF-8 字节，不持久化任何输入。

- 自定义深色码点、浅色背景，强制至少 4.5:1 明暗对比作为产品防护，并保留 4 模块留白；该阈值不是二维码识别成功的标准保证。可选 L/M/Q/H 容错等级；添加 Logo 自动使用 H。Logo 支持 PNG/JPG/WebP，最大 2 MB、1600 万像素，并在本地缩小和转为内嵌 PNG。
- 生成结果在 Worker 中用独立解码库回读，内容一致后开放下载。用户仍应在实际尺寸、设备、打印介质上扫码验证。PNG 可选 256/512/1024/2048 像素，内容过密时自动提高尺寸以保持每模块至少 4 像素；SVG 保留矢量码点与内嵌 Logo，无外部依赖。
- 上传或拖入 PNG/JPG/WebP 图片识别其中一枚二维码：单张最大 20 MB、3200 万像素、单边 10000 像素。先尝试最长边 1600，再尝试 2800 像素的图像；识别在可终止的 Worker 内执行。显示和复制原文，只有 HTTP(S) 内容显示用户主动打开的链接。并非所有模糊、遮挡或特殊编码的二维码都可识别。
- 使用本地提供的 Nayuki QR Code generator（MIT）及 jsQR 1.4.0（Apache-2.0），来源与许可证见 `src/vendor/README.md`，无需 npm 安装或第三方服务。静态二维码不依赖本站跳转服务。

## SVG 优化与转 PNG

入口：`/#svg`。支持上传、拖入或粘贴 UTF-8 SVG，最大 5 MB、5 万个元素、128 层嵌套。使用本地提供的 SVGO 4.1.0 浏览器包，在可终止的 Worker 中优化，20 秒超时；其他工具不会加载 SVGO 包。无需安装 npm 依赖或调用外部服务。

- 清除注释、编辑器数据及冗余属性，精简颜色、路径与变换。支持 2/3/5 位数值精度，默认 3 位；默认保留 ID、标题、描述、隐藏定义及 viewBox。可关闭 ID 保留，SVGO 会同步更新内部引用。浮点舍入和 SVG 特性可能影响显示，使用前应查看前后预览。
- 需要 viewBox 或明确宽高；支持 px/in/cm/mm/pt/pc/q 单位，百分比或自动尺寸按 viewBox 确定独立画布；缺少 viewBox 时按原始视口补齐。使用实际 UTF-8 字节统计，包括补齐画布后可能发生的体积增加；选择较小的有效规范化结果。
- 渐变、蒙版、裁剪、滤镜、文字、CSS 以及内嵌 PNG/JPG/WebP 可保留。工具处理独立静态 SVG，拒绝脚本、事件、动画、foreignObject、自定义 XML 实体、外部链接/图片/字体和样式导入。输入不会插入页面 DOM；解析发生在 Worker 内，预览仅使用 Blob SVG 的 `<img>`。文字仍依赖本机字体，内嵌位图不会因导出更大尺寸而增加细节。
- 优化后的 SVG 可下载或复制。PNG 由原始矢量内容按目标分辨率重新栅格化，支持透明/自选底色、1×/2×/4×、自定义宽高和比例锁定；解锁后等比居中留白。默认最长边不超过 2048，单边上限 8192、总像素上限 3200 万。更改输入或优化设置会使旧结果失效，避免下载旧文件。
- 库来源、完整许可证和依赖声明位于 `src/vendor/README.md`、`svgo.LICENSE.txt` 及 `svgo.NOTICES.txt`。

## 图片取色与配色板

- 独立入口 `/image-color-picker/`，兼容 `/#color`；已加入首页、图片分类、关键词搜索、侧栏和站点地图。

- 配色在最长边 256 px 的抽样图上提取：忽略全透明像素，半透明按白底合成。5 bit RGB 直方图归并相近颜色，使用 Oklab 感知空间的确定性加权聚类，最多 18 轮，独立 Worker 执行并设 12 秒超时。选择 5–8 色，色彩较少时按实际归组数返回，不补造颜色；比例为非全透明抽样像素的近似占比。代表色为所在组中最接近中心的直方图颜色，可能不是原图的某个精确像素。

## 图片水印与批量加水印

- 独立入口 `/image-watermark/`，兼容 `/#watermark`，包含首页入口、分类搜索、独立 SEO、FAQ、关联工具及站点地图。

- 单个或错行平铺水印，文字字号、Logo 宽度和边距以每张图片短边为基准；自定义中心位置按宽高百分比应用。单个水印支持九宫格、拖动、数字与键盘（1 px / Shift 10 px），旋转后的完整边界保持在画面内，超大水印等比缩小。平铺按旋转后的边界计算间距，边缘允许裁切；最多 600 个实例，过密时自动调大间距并提示。

- 原图、水印预览、实际编码结果可切换；修改设置立即清除旧结果并禁用下载。单图下载与 ZIP 使用独立结果，ZIP 沿用 UTF-8、CRC 和重名处理。当前单张结果可通过既有同源窗口握手送至压缩工具，需在 20 MB 以内；未新增上传接口或持久化图片。图像处理与打包使用现有本地工具链，无新增依赖。

## 图片转 PDF

- 独立入口 `/image-to-pdf/`，兼容 `/#imagepdf`；新增「文档与 PDF」分类，包含首页、搜索、侧栏、独立 SEO、FAQ 和站点地图。当前为 13 个工具、14 个规范页面。

- 一张图片一页。拖动手柄、上移/下移按钮或键盘调整顺序；焦点在手柄时，方向键移动一页，Home / End 移至首尾。点击缩略图或使用页码、上一页/下一页切换预览。

- 生成时逐张解码、处理、编码并释放完整画布和位图。内嵌图片合计与 PDF 均最高 100 MB；使用本站提供的 pdf-lib 1.17.1，优先在可终止 Worker 中生成，两分钟超时，不支持 OffscreenCanvas 时串行回退。停止会丢弃未完成 PDF 并保留源图和设置。
- 生成页预览使用实际内嵌 PNG/JPEG 解码后的缩略图及相同页面排版，预览不等于 PDF 阅读器渲染；原始清晰度请下载后检查。任何输入、顺序或设置修改会废弃旧结果。下载为图片型 PDF，不含 OCR 或可编辑文字；重新编码移除 EXIF 等图片元数据，页面刷新/关闭后清除，不新增服务器或持久化图片。
